ПУЛЬТ ЗАКАЗОВ ЦЕХА — сайт, который показывает данные из Excel

Состав папки:
  index.html          — сама страница
  xlsx.full.min.js    — библиотека для чтения Excel (не трогать)
  data/zakazy.xlsx    — ваш файл с заказами. Именно его вы обновляете.

Как обновлять данные:
  1. Вносите изменения в zakazy.xlsx (лист «Заказы», сотрудники — лист «Справочники»).
  2. Загружаете новую версию файла на хостинг в папку data с тем же именем zakazy.xlsx.
  3. Сайт подхватывает файл сам (кнопка «Обновить» или автоматически раз в 5 минут).

Важно: имя файла и названия колонок в строке заголовков («№ заказа», «Заказчик», «Срок сдачи», «Этап»,
«Кто делает сейчас» и т.д.) не меняйте — по ним сайт находит данные. Колонки можно переставлять.

Без хостинга: откройте index.html двойным щелчком и нажмите «Открыть файл…» — покажет дашборд по файлу с компьютера.
